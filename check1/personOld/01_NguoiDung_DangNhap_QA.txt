=== MUC 2: DANG NHAP & SESSION ===

CAU 6: Trinh tu dang nhap Admin nhu nao?
Tra loi: 
1. Truy cap /admin/login
2. AdminLoginServlet kiem tra Session
3. Nếu chưa đăng nhập → hien thi form login
4. Nhap SDT + mat khau
5. Query DB: SELECT * FROM NhanVien WHERE sdt=? AND mat_khau=?
6. Neu dung → luu vao Session (adminUser, adminId)
7. Chuyen ve /admin

CAU 7: Session la gi? Hoat dong nhu sao?
Tra loi: Session la co che luu trang thai giua cac request. 
- Khi đăng nhập thanh cong, luu thong tin vao Session
- Moi request sau do co Session ID (qua cookie)
- Server doc Session ID de biet ai đang đăng nhập
- Het han sau 30 phut hoặc khi logout

CAU 8: AdminAuthFilter la gi?
Tra loi: La bo loc (Filter) chay truoc moi request den /admin/*. 
- Kiem tra Session co adminUser khong
- Co → cho phep truy cap
- Khong → chuyen ve /admin/login

CAU 9: Code AdminAuthFilter nhu nao?
Tra loi:
@WebFilter(urlPatterns = {"/admin/*"})
public class AdminAuthFilter implements Filter {
    public void doFilter(ServletRequest request, ServletResponse response, 
                         FilterChain chain) 
            throws IOException, ServletException {
        HttpServletRequest req = (HttpServletRequest) request;
        HttpServletResponse resp = (HttpServletResponse) response;
        
        HttpSession session = req.getSession(false);
        if (session == null || session.getAttribute("adminUser") == null) {
            resp.sendRedirect(req.getContextPath() + "/admin/login");
            return;
        }
        
        chain.doFilter(request, response);
    }
}

CAU 10: AdminLogoutServlet lam gi?
Tra loi: Huy session va chuyen ve trang login.
- Lấy session hien tai
- Goi session.invalidate()
- Chuyen huong ve /admin/login

CAU 11: Bảng NhanVien co cac truong nao?
Tra loi: ma_nv (VARCHAR 10, PK), ten_nv (NVARCHAR 100), sdt (VARCHAR 15, UNIQUE), 
         chuc_vu (NVARCHAR 50), mat_khau (NVARCHAR 100).

CAU 12: Tại sao dung SDT de dang nhap?
Tra loi: Nhan vien thuong khong co email. SDT la dinh danh duy nhat va de nho.

CAU 13: Entity NhanVien dinh nghia nhu nao?
Tra loi: 
public static class NhanVien {
    public String maNv, tenNv, sdt, chucVu, matKhau;
}

CAU 14: Entity KhachHang dinh nghia nhu nao?
Tra loi:
public static class KhachHang {
    public String maKh, hoTen, sdt, email;
}

CAU 15: Mat khau luu co an toan khong?
Tra loi: Hien tai luu plain text (khong ma hoa) → khong an toan! 
         Trong thuc te phai dung BCrypt hoac SHA-256.
